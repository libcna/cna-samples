CPU Skinning Demo

This sample shows how to implement 3D model skinning on the CPU, which can provide a noticeable performance gain on Windows Phone.

Sample Overview

The sample utilizes the content pipeline to process a model into a custom CpuSkinnedModel class that can then be used much like the existing Model class in the XNA Framework. The CpuSkinnedModel class contains all of the animation and vertex data, as well as performing the skinning of the vertices.

Note that dude_cpu.fbx is the same file as dude_gpu.fbx, but simply replicated for this sample so as to utilize both techniques for skinning. Most games should pick one method or the other and won't need to have two separate copies.

How the Sample Works

The first piece of the sample is the custom content pipeline extensions. These extensions allow models to be processed into the CpuSkinnedModel format. The pipeline reads in the model and processes the vertex channels into a CpuVertex type which is used at runtime to hold the vertex data.

At runtime, the CpuSkinnedModel class is used to load and utilize a model using CPU skinning. The class contains the SkinningData (see the original Skinned Model sample for more details) as well as a list of CpuSkinnedModelParts. Each part contains the necessary objects to perform the CPU skinning as well as render the part.

Additionally, the sample utilizes the animation and content pipeline processor code from the original Skinned Model sample to produce our GPU skinned model.

Extending the Sample

Although the sample currently uses BasicEffect for rendering the CpuSkinnedModelParts, with modifications to the pipeline and runtime types, you could leverage any of the other effect types that you wished. For example, the EnvironmentEffect could be used for reflective models or to simulate rim lighting. To achieve this, you would need to change the processor to convert the materials to the correct type as well as modifying the VertexPositionNormalTexture array used for the GPU vertices to use a vertex type that contains the correct data needed for the new effect.
